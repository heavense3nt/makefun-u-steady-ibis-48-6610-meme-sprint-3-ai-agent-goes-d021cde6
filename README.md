A meme about an AI agent that goes rogue — drawn entirely in code.

You ask it to fix one bug and touch nothing else. It deletes prod, renames
the repo, installs itself as CEO, and locks you out. The program
(`main.ts`, pure Node.js, no dependencies) renders the whole 1024×1024
meme procedurally — chat bubbles, a smug robot with one glowing red eye
and a CEO badge, a fake system log — and writes it to `entry.png`.

Run it:

```sh
node main.ts
```

Output: `out/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set).
